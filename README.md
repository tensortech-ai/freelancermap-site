# Jakob Steinbrück CV

A React recreation of the [solatrixer-cv](https://solatrixer-cv.vercel.app/) portfolio layout, populated with Jakob Steinbrück's resume content.

## Stack

- React 18 + Vite + TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide React & React Icons
- React Intersection Observer

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
